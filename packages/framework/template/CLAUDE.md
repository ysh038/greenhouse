# 이 프로젝트에서 일하는 방식

화면 코드는 `@agent-greenhouse/framework`의 API로 만듭니다. 작업을 시작하기 전에 안내 문서를 읽습니다.

- 안내 문서: `node_modules/@agent-greenhouse/framework/GUIDE.md`
- 각 API의 인자와 설명: `node_modules/@agent-greenhouse/framework/dist/<모듈>/*.d.ts`

## 확인

작업을 마쳤다고 하기 전에 `npm run check`가 통과해야 합니다. 타입 검사, 린트, 테스트, 빌드, 화면 검증을 차례로 돌립니다.

화면을 바꿨으면 그 화면의 시나리오(`*.verify.ts`)도 바뀐 동작을 다루도록 고칩니다. 새로 생겼거나 달라진 스크린샷은 모아 보기를 열어 본 뒤 기록해야 통과합니다. 어색한 곳이 보이면 기록하지 말고 고칩니다.

## 지킬 것

- 린트와 타입 검사 규칙을 끄거나 우회하지 않습니다. 설정 파일은 고치지 않습니다.
- `node_modules` 안의 파일은 고치지 않습니다. 프레임워크에 없는 것이 필요하면 사람에게 알립니다.
- 기능마다 `src/<기능>/` 폴더를 만들고 화면, 데이터, 테스트, 시나리오를 같이 둡니다.
