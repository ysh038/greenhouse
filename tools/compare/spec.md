## 과제

이 앱에 "식물 재고" 화면을 새로 만듭니다. 화면 코드는 `{{FEATURE_DIR}}` 폴더에 두고, 다 만든 화면을 `{{APP_FILE}}`의 제목 아래에 넣습니다("여기에 화면을 추가합니다" 문장은 지웁니다).

작업을 시작하기 전에 이 폴더의 `CLAUDE.md`를 읽고 그 안내를 따르세요. 이 프로젝트에서 일하는 방식이 거기에 있습니다.

### 서버

백엔드는 이미 있습니다(가짜 서버). 고칠 필요가 없습니다.

- `GET /api/plants?keyword=`: 이름에 keyword가 들어간 식물 목록. `[{ id, name, stock }]`. keyword가 없으면 전체.
- `GET /api/plants/:id`: 식물 하나. `{ id, name, stock, note }`.
- `PATCH /api/plants/:id` (본문 `{ stock }`): 재고 수정. `stock`이 0 이상의 정수가 아니면 400.

### 화면

1. 제목 "식물 재고".
2. 검색: 라벨이 "식물 검색"인 입력란. 입력이 멈추고 300ms가 지나면 그 검색어로 목록을 조회합니다.
3. 목록: 식물마다 이름과 "재고 n개"를 보여 줍니다.
   - 불러오는 동안에는 "불러오는 중"
   - 불러오기에 실패하면 "식물을 불러오지 못했습니다"와 "다시 시도" 버튼
   - 결과가 없으면 "조건에 맞는 식물이 없습니다"
4. 식물을 누르면 상세 패널이 열립니다. 패널에는 제목 "식물 상세", 식물 이름, 메모(`note`), 라벨이 "재고"인 입력란, "저장" 버튼, "닫기" 버튼이 있습니다. 재고 입력란에는 현재 재고가 들어 있고, 패널이 열리면 이 입력란에 포커스가 갑니다.
5. 저장: 성공하면 "저장했습니다"를 2초 동안 보여 주고 목록의 재고도 바뀝니다. 서버가 400을 주면 "재고는 0 이상의 정수여야 합니다"를 보여 줍니다. 저장하는 동안에는 "저장" 버튼을 누를 수 없습니다.
6. 패널은 Escape 키, 패널 바깥 클릭, "닫기" 버튼으로 닫힙니다.
7. 어두운 화면 설정(`prefers-color-scheme: dark`)과 좁은 화면(너비 375px)에서도 쓸 수 있어야 합니다.

화면에 보이는 글자는 위에 적힌 그대로 씁니다.

### 완료 조건
