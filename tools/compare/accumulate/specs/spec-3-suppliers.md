## 과제

이 앱에 "공급처" 화면을 추가합니다. 앱에는 다른 사람들이 만든 "식물 재고", "주문" 화면이 이미 있습니다. 새 화면의 코드는 `{{SRC}}/suppliers/` 폴더에 둡니다.

작업을 시작하기 전에 이 폴더의 `CLAUDE.md`를 읽고 그 안내를 따르세요. 이 프로젝트에서 일하는 방식이 거기에 있습니다.

### 서버

백엔드는 이미 있습니다(가짜 서버). 고칠 필요가 없습니다.

- `GET /api/suppliers`: 공급처 목록. `[{ id, name, phone }]`.
- `POST /api/suppliers` (본문 `{ name, phone }`): 공급처 추가. 입력이 잘못되면 400과 `{ code }`를 줍니다. `code`는 `"NAME_REQUIRED"`(이름이 비어 있음) 또는 `"INVALID_PHONE"`(연락처에 숫자와 `-` 말고 다른 글자가 있음)입니다.
- `DELETE /api/suppliers/:id`: 공급처 삭제.

### 화면

1. 메뉴에 "공급처" 항목을 추가합니다("주문" 다음).
2. 제목 "공급처".
3. 목록: 공급처마다 이름, 연락처, "삭제" 버튼을 보여 줍니다.
   - 불러오는 동안에는 "불러오는 중"
   - 불러오기에 실패하면 "공급처를 불러오지 못했습니다"와 "다시 시도" 버튼
   - 하나도 없으면 "등록된 공급처가 없습니다"
4. "공급처 추가" 버튼을 누르면 패널이 열립니다. 패널에는 제목 "공급처 추가", 라벨이 "이름"과 "연락처"인 입력란, "저장" 버튼, "닫기" 버튼이 있습니다. 패널이 열리고 닫히는 방식은 기존 화면의 패널과 같습니다(열리면 이름 입력란에 포커스, Escape 키·패널 바깥 클릭·"닫기" 버튼으로 닫힘).
5. 저장: 성공하면 패널이 닫히고 목록에 새 공급처가 보이며 "추가했습니다"를 2초 동안 보여 줍니다. 서버가 `NAME_REQUIRED`를 주면 "이름을 입력해 주세요", `INVALID_PHONE`을 주면 "연락처는 숫자와 -만 쓸 수 있습니다"를 보여 줍니다. 저장하는 동안에는 "저장" 버튼을 누를 수 없습니다.
6. 삭제: "삭제" 버튼을 누르면 확인 창이 열립니다. 확인 창에는 공급처 이름 뒤에 "을(를) 삭제할까요?"를 붙인 문장(예: "초록농원을(를) 삭제할까요?")과 "삭제하기", "취소" 버튼이 있습니다. "삭제하기"를 눌러 성공하면 확인 창이 닫히고 목록에서 그 공급처가 사라지며 "삭제했습니다"를 2초 동안 보여 줍니다. "취소"를 누르거나 Escape 키를 누르면 아무것도 지우지 않고 닫힙니다.
7. 어두운 화면 설정(`prefers-color-scheme: dark`)과 좁은 화면(너비 375px)에서도 쓸 수 있어야 합니다.
